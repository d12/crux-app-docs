# Setting Climbs

## How Crux Differs from Other Apps

Most climbing apps use a **single static photo** of a wall where you select holds to create climbs.

Crux is **more flexible**:
- Gyms and homewalls can save **walls**: a scanned photo of a spray wall or board, where you just tap holds to set.
- At gyms that allow it, you can also **take or upload a new photo for each climb**, so you can set on any wall in the gym. If the holds change, just take a fresh photo.

To save time, you can also **re-use recently scanned photos**. More on that below!

## How to Set a Climb

1. **Open the climb list** – Tap **"Climbs"** on the main gym page.
2. **Tap the round "+" button** – This opens the new climb form.
3. **Choose a wall or photo** – **"Select a saved wall"**, or **"Scan an image"** to take a new photo, upload one, or re-use a recent one. (What you see depends on the gym's walls and settings.)
4. **Select holds** – Tap holds, and add circuits, drawings or a crop if you like. Tap the checkmark when done.
5. **Enter climb details** – Add a **climb name**, **proposed grade**, **feet rules**, and any other details.
6. **Tap "Post climb"** – Your climb is now live for others to try. Nice work! (Or tap **"Save draft"** to finish it later; only you can see drafts.)

:::info
At gyms on Crux's **free tier**, each climber can post up to **2 climbs per day**, and some editor tools (like circuits) are locked.
:::

The next sections break down these features in more detail.

## Re-Using Photos

Crux **saves the photos you scan** to the gym's photo library. This makes it easy to re-use recent images instead of taking new ones each time.

### Selecting a Recently Used Photo
1. On the photo selection screen, tap **"Scan an image"**, then **"Use a recently scanned photo"** (or **"Or, use a photo from a recent climb"** at gyms without saved walls).
2. Select a photo from the **recent library** to open it in the image editor.

<img src="/img/uploading-a-recent-photo.png" alt="Selecting a recently used photo for your climb" class="screenshot" />

### Pinning Frequently Used Photos
Gym admins can **pin** often-used photos to the top of the library:
1. Tap the **⋮** in the top-right of the photo.
2. Select **"Pin photo"**.

## Editing Your Image

The image editor's tools are on the toolbar at the right.

### Finding Holds
1. Tap the **wand icon**.
2. Crux scans the image for holds ("Finding climbing holds…" takes a few seconds).
3. When scanning is complete, the detected holds are outlined. Tap them to select them! Tap a selected hold again to change its type (start, hand, foot, finish…).

:::tip
**Hold positions are saved** with each photo, so you won't need to rescan when you re-use it. On saved walls, the holds are already found.
:::

:::warning
If holds aren't detected correctly, make sure the image is **well-lit, clear, and taken straight on**.
:::

### Creating Circuits
1. Select holds for your climb.
2. Tap the **# icon**.
3. Tap the holds in the order you'd like them numbered.

### Drawing on the Image
Use the **pencil icon** to mark beta, cross out off-limits holds, or indicate start positions.

### Cropping the Image
Tap the **crop tool**, adjust the crop box, and confirm with the checkmark button.

### Climb Appearance
How climbs are drawn (outline style, thickness, labels, how dark the wall is, hold colors) is set in **Climb appearance**:
- For yourself: profile **settings cog → "Climb appearance"**.
- For the whole gym: gym admins use **Gym Settings → "Climb appearance"**.

## Proposed Grade

When you post a climb, you can:
- Set a **proposed grade**
- Leave it **ungraded** and let climbers vote

At most gyms, the grade automatically adjusts as climbers suggest grades when they log sends.

:::warning
Homewall admins can turn off **"Automatically re-grade climbs based on climber consensus"** in their wall settings. Then setter-proposed grades are final.
:::

## Feet Rules

Feet rules define which holds can be used as footholds:
- **Feet follow hands** – Any marked hold can be used for feet.
- **Feet follow hands, open kicker** – Same as above, plus **all holds on the kickboard are allowed**.
- **Only marked feet** – Only holds marked as feet can be used.
- **Campus (no feet)** – No footholds allowed.
- **Any feet** – Any hold on the wall can be used for feet.

You can also say whether **matching** is allowed. Gyms can turn rules off or add their own under **Gym Settings → "Feet and matching rules"**.

## Tags

Tags make climbs easier to find! For example, if a climb is **slopey**, tag it as **"Slopey"** so others can filter for similar climbs. Gyms can add their own tags too.
